### 4.2 The bar rule (W-b), `barSend`

```
groups = unsentGroups(lines)          // per course in service order: non-segue drafts, no queued fire/void (QW12 rule)
return groups.find(g => g.course === selected) ?? groups[0] ?? null
```

- The ids are exactly the sheet's `fireGroups(...).normalIds` for that course: same lines, same filter.
- Queued adds count; the outbox orders the fire after them.
- The bar label is `sendLabel(course, ids.length)`.

| `tables.tile.openedAria` | {waiter} alle {when} | {waiter} at {when} | **da approvare** |

`tileLabel` joins these parts with ", ":
- the name;
- `statusWord`;
- `coversLine`;
- `tables.tile.openedAria` (with the date form of `openedLine` when the table was not opened today);
- `unsentDishes(n)` when n > 0.

The spec's example becomes "Tavolo 2, Aperto, 4 coperti, Giulia alle 20:14, 2 piatti da inviare".

## 9. Build-queue items for the platform builder

**BQ-1 · `unsentCount` on `GET /api/tables`** (blocks P3-10 and P3-11)
- **Contract:** `tablesListOutput.tables[].session.unsentCount: z.number().int().nonnegative()`. It goes in `tileSession`
  (`src/server/tables/output.ts:43-51`), so it is present on every tile that has a session and absent when `session` is `null`.
- **Meaning:** the number of the session's order lines with `state = 'draft'` and `segue = false`.
  - Fired and voided lines are excluded by state.
  - A line removed before sending is not counted, as `/api/table-sessions/:id/lines` does not return it.
