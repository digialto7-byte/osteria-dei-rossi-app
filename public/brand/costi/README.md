# Costì logo slots

Generated by `npx tsx scripts/brand/render-icons.ts`. Do not edit by hand: run the script. The paths are named in
`src/lib/brand/costi-assets.ts`, which a logo swap never edits.

**The SVGs here are placeholders** (each root `<svg>` carries `data-costi-placeholder="true"`) until the founder's vector files
arrive. Go-live row BRAND-1 (`docs/go-live/checklist.md`) blocks go-live while any remains:
`grep -l data-costi-placeholder public/brand/costi/*.svg` must print nothing, unless the founder approves the placeholders.

## Slots

| Slot (source file)             | Shape the founder delivers                                                | Consumers                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `app-icon.svg`                 | Square viewBox, full-bleed background.                                    | icon-192.png, icon-512.png, apple-touch-icon.png; manifest icons (any), root metadata apple icon |
| `app-icon-maskable.svg`        | Square, artwork inside the central 80 % safe zone, full-bleed background. | icon-maskable-192.png, icon-maskable-512.png; manifest icons (maskable)                          |

| `logo-horizontal-reversed.svg` | Mark and wordmark, for Forest and Charcoal.                               | ProductLogo (dark, through <picture>)                                                            |
| `mark.svg`                     | The mark alone, light backgrounds.                                        | none yet (reserved)                                                                              |
| `mark-reversed.svg`            | The mark alone, for Forest and Charcoal.                                  | none yet (reserved)                                                                              |
| `wordmark.svg`                 | The wordmark alone, light backgrounds.                                    | none yet (reserved)                                                                              |
| `wordmark-reversed.svg`        | The wordmark alone, for Forest and Charcoal.                              | none yet (reserved)                                                                              |

## Delivery rules

- Root `<svg>` with a `viewBox` (square for `app-icon.svg`, `app-icon-maskable.svg` and `favicon.svg`).
- No `<script>`, `<foreignObject>`, `on*` attributes, `<image>`, external `href`, `@import` or `url(http`.
- Text converted to outlines (no `<text>`).
- No `data-costi-placeholder` attribute.

## Swapping in the founder's files

1. Replace the nine SVGs (same names).
2. Run `npx tsx scripts/brand/render-icons.ts`.
3. Commit the SVGs, the six PNGs, `renders.json` and this README. No file under `src/`, `tests/`, `e2e/` or `scripts/` changes.

`tests/config/costi-brand-assets.test.ts` fails if an SVG breaks a rule or if a PNG was not re-rendered from the SVG in the tree.
